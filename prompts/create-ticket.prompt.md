# Create a Jira Ticket

I'll help you create a clear, well-structured Jira ticket. I'll ask a few quick questions first, then create it with your confirmation.

## Let's gather the details

Please answer these questions (you can answer all at once or I'll ask one by one):

1. **What's the ticket about?** — Describe the task, bug, or idea in plain language. A sentence or two is fine.
2. **What type is it?** — Bug, Task, Story, Improvement, or not sure?
3. **How urgent is it?** — Critical (everything stops), High (this week), Medium (soon), or Low (whenever)
4. **Who should do it?** — A specific person, or leave it unassigned?
5. **Which project does it belong to?** — The project key (e.g., MUS, PROJ) or the project name

---

## What I'll do with your answers

- Write a clear, professional ticket title
- Write a description with enough detail for whoever picks it up
- Set the right priority and issue type
- Show you the full ticket for review **before** creating it in Jira
