# Guide 2 — Setting Up VS Code and GitHub Copilot

> Estimated time: 10–15 minutes

---

## What you'll have at the end

- VS Code installed on your computer
- GitHub Copilot extension installed
- Your GitHub account connected
- A working chat window where you can talk to your assistant

---

## Step 1 — Install VS Code

1. Go to [code.visualstudio.com](https://code.visualstudio.com)
2. Click the big blue **Download** button (it auto-detects your operating system)
3. Open the downloaded file and follow the installation steps
4. Open VS Code when it's done

> **Tip:** VS Code looks like a code editor, but you don't need to write any code. You'll mostly use the Chat panel on the side.

---

## Step 2 — Create a GitHub Account (if you don't have one)

1. Go to [github.com](https://github.com)
2. Click **Sign up**
3. Follow the steps — you just need an email and a password
4. Verify your email

---

## Step 3 — Get a GitHub Copilot Subscription

GitHub Copilot requires a paid subscription (or a free trial).

1. Go to [github.com/features/copilot](https://github.com/features/copilot)
2. Click **Start a free trial** or **Get Copilot**
3. Choose a plan — **Copilot Individual** is fine for personal use
4. Follow the billing steps

> **Note:** If your company provides GitHub Copilot, ask your IT team or manager for access — you won't need to pay.

---

## Step 4 — Install the GitHub Copilot Extension in VS Code

1. Open VS Code
2. On the left side, click the **Extensions** icon (it looks like 4 squares)
3. In the search box at the top, type: `GitHub Copilot`
4. Click **Install** on the result called **"GitHub Copilot"** (by GitHub)
5. Also install **"GitHub Copilot Chat"** if it appears as a separate item

---

## Step 5 — Sign In to GitHub in VS Code

1. After installing, VS Code will ask you to sign in to GitHub
2. Click **Sign in to GitHub**
3. A browser window will open — log in to your GitHub account
4. Click **Authorize** to give VS Code access
5. The browser will redirect back to VS Code automatically

You'll see a small GitHub icon in the bottom-left corner of VS Code when you're signed in.

---

## Step 6 — Open This Kit in VS Code

1. In VS Code, go to **File** in the top menu
2. Click **Open Folder**
3. Navigate to the folder where you saved this kit
4. Click **Open**

VS Code will load all the files and settings from this kit automatically.

---

## Step 7 — Open the Chat Panel

1. Look for a chat bubble icon in the left sidebar of VS Code (or press `Ctrl+Shift+I` on Windows)
2. The Chat panel will open on the right or left side
3. At the bottom of the chat, you should see a dropdown — make sure **Agent** is selected
4. Type a message and press Enter

**Try this as your first message:**
```
Hello! What can you help me with?
```

---

## Troubleshooting

**I don't see the chat icon**
→ Go to View → Open View → GitHub Copilot Chat

**It says "not signed in"**
→ Click the person icon at the bottom-left of VS Code and sign in to GitHub

**It says "no subscription"**
→ Make sure your GitHub account has an active Copilot subscription at [github.com/settings/copilot](https://github.com/settings/copilot)

**The Agent option isn't showing**
→ Check that you have the latest version of the GitHub Copilot extension (click the Extensions icon, find GitHub Copilot, and check for updates)
